# Timeline screenshot

Captured from the running Go application with an isolated sample stream.
The reflections are fictional demo data, not posts from real users. No sample
content was sent to the public server. The interface is the real application.

Sample photography from Unsplash:

- Beach sunrise: [Bekah Horgen](https://unsplash.com/photos/sunrise-over-a-calm-ocean-beach-GJKbtvKh8Q4).
- Trees and sunlight: [Sergej Karpow](https://unsplash.com/photos/bare-tree-on-grassy-hill-with-surrounding-foliage-l2Olqxu8vgE).

The local binary was built from the repository with `go build -buildvcs=false`.
The sample posts and photographs were loaded through the normal persisted
stream format, then displayed in `#morning` and captured in a browser.
